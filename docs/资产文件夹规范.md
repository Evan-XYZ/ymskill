# 资产文件夹规范 · 你的投资文件夹长什么样

> 这套 Skills 只负责「怎么做」：怎么看变化、怎么开原件、怎么过门禁、怎么记账。
> 「你是谁、你做哪类机会、用什么尺子、什么时候认错」，写在你自己电脑上的一个文件夹里。
> 每个 Skill 开工前先读这个文件夹；你没写的部分，它不替你编，会停下来请你先补上。

---

## 一、一句话

**Skill 是动作，文件夹是你。** Skill 可以换、可以改、可以删；文件夹里你写下的目标、尺子、规则、记录和复盘，才是越用越值钱的那部分。换一个 Agent，它读同一个文件夹，照样接得上。

```text
┌──────────────────────────────┐        ┌──────────────────────────────┐
│ Skills（公共的动作）           │  读 →  │ 你的投资文件夹（私有的你）     │
│ 看变化 · 开原件 · 两把尺子     │        │ 目标与尺子 · 观测清单 · 规则   │
│ 买入门禁 · 记账 · 回看 · 交接  │  ← 写  │ 研究档案 · 交易记录 · 复盘     │
└──────────────────────────────┘        └──────────────────────────────┘
          可以照搬                                只能你自己写
```

## 二、标准目录

Skills 默认按下面的路径读写。你已经有自己的文件夹（比如在用 YMOS 或自己的 Obsidian 库），不用改目录，在说明书里写一段「路径映射」就行（见第五节）。

```text
<你的投资文件夹>/

│
├── 01_我的投资框架/                ← 整套系统的「宪法」，只有你能定稿
│   ├── Strategy_Profile.md        我的目标、每个目标的四问与尺子、失效条件
│   ├── 观测清单.md                 看哪几个维度、哪些信源、什么才算变化
│   └── 长期规则.md                 红线和已经批准的规则（改动走 yms-review 的规则变更）
│
├── 02_研究档案/                    一个板块或一家公司一份：<名称>.md
│
├── 03_每日观测/
│   ├── YYYY-MM-DD_每日观测.md      只写变化
│   ├── 事件登记.md                 S / A 级事件登记，留着以后回头对结果（只追加）
│   ├── 核实记录/                   开原件核实，一件事一份
```

## 三、谁能写什么

| 文件 | 谁定稿 | Agent 能做什么 |
|:---|:---|:---|
| `01_我的投资框架/` 三个文件 | **你** | 通过对话帮你起草，你说「确认」才写入；之后只能提修改建议 |
| `04_决策与交易记录/` 里你写的内容 | **你** | 只读；`门禁日志.md` 只能在末尾追加；`券商导出/` 由你放进去 |
| `02_研究档案/` | Agent 追加 | 在文件末尾追加带日期的一节；你手写的段落不改 |
| `03_每日观测/` `05_复盘/` `06_BrainStorm/Insight/` `06_BrainStorm/回看/` | Agent 写 | 写入并标注来源和日期；追加型文件（事件登记、回看台账）只追加不改旧行 |
| `06_BrainStorm/原始想法/` `06_BrainStorm/动作记录/` | 你说，Agent 记 | 原话按顺序保留，不改写 |
| `06_BrainStorm/MEMORY.md` `STATUS.md` `感悟归档/` | **你** | Agent 起草，你说「确认」才写入；没人看着的时候只写候选 |
| `06_BrainStorm/历史资料/原始资料/` | **你** | 只读，不改、不移动 |
| `07_主控/` | Agent 写 | 交接里你写的批示一个字不改 |

三条任何 Skill 都不能越过的线：

1. **不下单**。整套东西不接任何交易接口，真实买卖由你自己在券商 App 上手动完成。
2. **不替你做买卖决定**。Skill 的输出只用「看 / 核 / 等 / 对照」这类研究动作收尾，不出现「买入 / 卖出 / 目标价」。
3. **不改评价自己的尺子**。`01_我的投资框架/` 和回看台账的统计口径，只有你能改。

## 四、「写不清的地方」怎么处理

每个 Skill 的开头都有一段**前置检查**，列出它要读的文件和字段。

```text
要读的文件不存在           → 停下，告诉你先跑哪个动作（例如 yms-setup 的策略档案）
字段还是「【待填】」        → 停下，指出是哪个字段，问你现在补，还是这次先跳过
你明确说「这次先跳过」      → 可以继续，但输出里写明「缺 X，以下结论不含这部分」
```

**它不会用常识替你补齐。** 一份没写尺子的 Profile，Agent 补出来的只会是一把四平八稳的通用尺子，量什么都差不多。你写不清的地方，就是它帮不上的地方；先把这个地方暴露出来，本身就是这套东西的第一个用处。

模板里所有要你填的地方，统一写作 `【待填】`。

## 五、路径映射（已经有自己文件夹的人看这里）

在说明书（`AGENTS.md` / `CLAUDE.md`）里加一段，Skill 会先读它再找文件：

```markdown
## 路径映射
- Strategy_Profile = Brain/Strategy_Profile.md
- 观测清单 = 持仓与关注/当前关注方向与投资偏好.md
- 长期规则 = BrainStorm/MEMORY.md
- 每日观测 = Eyes/市场洞察/
- 交易记录 = Console/账本/
- BrainStorm = BrainStorm/
- 主控 = 投资主控/
```

没写映射的项，按第二节的标准路径找。

## 七、为什么是文件夹

- **归你所有**：文件在你硬盘上，断网能用，不怕平台关停；
- **不锁工具**：今天用 Claude Code，明天换 Codex 或豆包电脑版，读的是同一个文件夹；
- **Agent 最好读**：模型天然擅长读写 Markdown；
- **越用越像你**：每一次门禁、每一笔复盘、每一条批准的规则都留在这里。聊天记录不是资产，文件夹才是。
