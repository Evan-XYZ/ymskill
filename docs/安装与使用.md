# 安装与使用

> 工具每个月都在变，这里只写不太会变的部分。具体到某个工具的按钮在哪，以它的官方最新版本为准。

---

## 一、你需要什么

- **一个 Agent**：海外路线用 Claude Code 或 Codex（二选一当主力）；国内路线用豆包电脑版或 WorkBuddy。
- **一个本地文件夹**：你的投资框架、研究、交易记录和复盘都放在这里。没有也没关系，装完让 AI 帮你建。

不需要 API Key，不需要券商账户权限。这套东西没有任何下单接口。

---

## 二、四种装法

### 1. 发一句话给你的 AI（推荐）

```text
帮我从 https://github.com/Evan-XYZ/ymskill 安装 ymskill：先读仓库里的 AGENTS.md，按它的步骤装好；装完问我想先试一下，还是先建投资文件夹；最后用 /yms 帮我做一次起点诊断，告诉我先从哪个动作开始。
```

### 2. Skills CLI

```bash
npx -y skills add Evan-XYZ/ymskill -g -y --skill '*'
```

`-g` 装到用户级目录；`--skill '*'` 装全部 8 个模块；`-y` 不逐项确认。它会自动找到你电脑上已经装了的 Agent，只装到这些里面。只装一个就写明 `--agent claude-code`。不要加 `--all`：它会给几十个你没装的 Agent 都在用户目录下建文件夹。

### 3. Claude Code 插件市场

```bash
claude plugin marketplace add Evan-XYZ/ymskill
claude plugin install ymskill@ymskill
```

命令会带 `ymskill:` 命名空间，例如 `/ymskill:yms`。

### 4. 自己复制

```bash
git clone https://github.com/Evan-XYZ/ymskill.git
cp -R ymskill/skills/yms* ~/.claude/skills/
```

- 上面是 Claude Code 的用户级目录。只想在某个文件夹里用，就复制到 `<那个文件夹>/.claude/skills/`。
- Codex 放进 Codex 的 Skills 目录。
- 复制整个模块文件夹，里面的 `references/`、`templates/`、`scripts/` 都要带上。

### 只能对话的工具

ChatGPT、Claude、Gemini、豆包、DeepSeek、WorkBuddy 这类只能对话的工具，没有 Skills 机制也能用：

1. 打开要用的模块的 `SKILL.md`，看「这个模块里有什么」，找到对应的动作；
2. 打开那一份 `references/<动作>.md`，把正文整个复制进对话；
3. 把它要读的文件（比如你的策略档案）一起贴进去，或者让工具读你的本地文件夹。

每一份动作文件都写成能单独读懂的样子。没有定时任务，就每天手动跑同一条，一样能积累。

## 三、第一次用

| 顺序 | 你说 | 用到 |
|:---|:---|:---|
| 1 | 「从哪开始」 | `yms` · 起点诊断 |
| 2 | 「帮我建投资文件夹」 | `yms-setup` · 建文件夹 |
| 3 | 「帮我梳理策略」 | `yms-setup` · 策略档案 |
| 4 | 「我该盯什么」 | `yms-setup` · 观测清单 |
| 5 | 之后每天：「今天什么变了」 | `yms-watch` · 每日变化 |

第 3 步最花时间，也最值钱。写不出来的地方留着 `【待填】`，那就是这套东西帮你暴露出来的第一个问题。

之后按你的卡点往下走：

| 你的处境 | 先用 |
|:---|:---|
| 每天被快讯淹没 | `yms-watch`：每日变化 → 事件分级 → 开原件核实 |
| 研究碎片化，问 AI 得到的都是正确的废话 | `yms-think`：两把尺子 → 核心资产七问 / 反向 DCF |
| 收盘想明白，盘中又冲动；看对了没拿住 | `yms-gate`：买入门禁 → 卖出对照 → 操盘台 |
| 复盘容易自欺，一亏就想改规则 | `yms-review`：持有期复盘 → 三红旗 → 规则变更 |
| 流程多到按不过来 | `yms-autopilot`：定时任务说明 → 主控心跳 |

**自动化永远放在最后。**哪条流程手动跑顺了、至少跑过三期，再交给定时任务。

## 四、已经有自己的文件夹

不用改目录。让 AI 跑 `yms-setup` 的建文件夹，它会走「已有文件夹」分支：读一遍你的目录，起草一段「路径映射」给你确认，确认后追加到你的说明书（`AGENTS.md` / `CLAUDE.md`）末尾。之后每个动作都先读这段映射再找文件。

---

## 五、更新

Skills 和你的文件夹是分开的。更新只换 `skills/` 下的模块文件夹，你的文件夹一个字不动：

```bash
cd ymskill && git pull
cp -R skills/yms* ~/.claude/skills/
```

用 Skills CLI 装的，再跑一次安装命令；用 Claude Code 插件装的，`claude plugin update ymskill@ymskill`。也可以直接在 Agent 里说 `/yms 更新`。

你自己改过某个动作文件的，更新前先备份那一份，更新后再对照着合进去。

## 六、常见问题

**它会帮我下单吗？**
不会。没有任何交易接口，这是刻意的。真实买卖你自己在券商 App 上手动完成。

**要把 7 个模块都装上吗？**
装上不会占多少地方：Agent 平时只看到每个模块的名字和一两句描述，你用到哪个动作才读哪一份。但用起来，从你的卡点开始，一次只加一个；不知道从哪开始，说 `/yms`。

**我的数据去哪了？**
都在你自己电脑上的文件夹里。向云端模型提问时，资金量用百分比，不写金额；账户号、密码、API Key 任何时候都不交给 AI。

**能改吗？**
能。每个动作都是一份纯 Markdown，打开就能改。想加一个自己的动作，照着 [Skill编写规范](Skill编写规范.md) 写。

**和 YMOS 什么关系？**
YMOS 是我自己那一版的完整系统，带着我的目标和能力圈；这里是从里面抽出来的公共动作，配一个由你自己填的文件夹。用它搭出来的，应该是你自己的那一版。
