# ymskill

**把你的投资判断写进一个 AI 读得懂的文件夹，再让 Agent 按你的规矩帮你看、帮你拦、帮你记账。**

[![Version](https://img.shields.io/badge/version-1.0.1-A6533C.svg?style=flat-square)](VERSION)
[![License](https://img.shields.io/badge/license-CC%20BY--NC%204.0-2F7857.svg?style=flat-square)](LICENSE)

ymskill 是《AI 投资指南》8 篇的可运行版本：一个总入口、7 个模块、28 个投资流程动作，装进你自己的 Agent 就能用。作者：勇麦（十一年 A 股 + 美股实盘，一年多重度用 AI 做投研、决策和复盘）。

- **装上就能用**：Claude Code（推荐）· Codex · Cursor · OpenClaw · Hermes · Gemini CLI · Trae · CodeBuddy，以及其他支持 Agent Skills 的 Agent
- **复制进对话也能用**：ChatGPT · Claude · Gemini · Grok · 豆包 · DeepSeek · Kimi

> 不荐股，不预测，不接交易。判断永远是你的；这些 Skill 管的是流程。

**你是 Agent？** 先读 **[AGENTS.md](AGENTS.md)**。

```text
帮我从 https://github.com/Evan-XYZ/ymskill 安装 ymskill：先读仓库里的 AGENTS.md，按它的步骤装好；装完问我想先试一下，还是先建投资文件夹；最后用 /yms 帮我做一次起点诊断，告诉我先从哪个动作开始。
```

想自己在终端装，跳到 **[安装](#安装)**。

## ymskill 是什么

**一套公共的动作，加一个你自己的文件夹。**

```text
┌──────────────────────────────┐        ┌──────────────────────────────┐
│ ymskill（公共的动作）          │  读 →  │ 你的投资文件夹（私有的你）     │
│ 看变化 · 开原件 · 两把尺子     │        │ 目标与尺子 · 观测清单 · 规则   │
│ 买入门禁 · 记账 · 回看 · 交接  │  ← 写  │ 研究档案 · 交易记录 · 复盘     │
└──────────────────────────────┘        └──────────────────────────────┘
          可以照搬                                只能你自己写
```

- **Skill 是动作**：怎么看变化、怎么开原件、怎么过门禁、怎么记账。每个都是纯 Markdown，打开就能读、能改。
- **文件夹是你**：你做哪几类机会、每一类用什么尺子、什么时候认错、你的交易和复盘。这部分我给不了，也不该给。
- **它们怎么配合**：每个动作开工前先读你的文件夹。你没写的部分，它不拿常识替你补，会停下来告诉你缺什么。**你写不清的那部分，就是 AI 帮不上的那部分**——先把它暴露出来，是这套东西的第一个用处。

不知道该用哪个，从 **`/yms`** 开始。它读你说的情况，推荐 1 个主动作（最多再加 2 个辅助），说明为什么，再交给对应的模块去做。你不用记 28 个动作的名字。

**它不是什么**

- **不是荐股，不是预测**。没有买卖点，没有目标价，不承诺任何收益。
- **不是量化黑盒，也不是高频**。不用模型预测涨跌，不挖因子，不拼速度。
- **不接交易**。没有任何下单接口，真实买卖由你自己在券商 App 上手动完成。这是刻意的。
- **不是我的策略**。我的尺子、仓位、偏好不在这里面。Skill 里只有结构，参数从你的文件夹里读。

文件夹的完整规范见 **[docs/资产文件夹规范.md](docs/资产文件夹规范.md)**。

## 三件东西：方法、动作、打样

ymskill 之外，还有两样东西。三样各管一段：

| | 是什么 | 适合谁 |
|:---|:---|:---|
| **[《AI 投资指南》](https://yongmai.xyz/ai-invest-guide/)** | **方法**。8 篇讲清楚每一步为什么这么做、我踩过什么坑。它是源头，照着它，你可以从零搭出自己和 AI 协作做投资的那一套 | 想弄懂原理、想自己搭 · [仓库](https://github.com/Evan-XYZ/ai-invest-guide) |
| **ymskill**（这个仓库） | **动作**。把指南里反复要做的事抽成一个个能直接调用的动作，按模块分好，可以理解成提示词的升级版。你的判断写在你自己的文件夹里，它照着干活 | 已经有自己的笔记或流程，想让 AI 按规矩干活 |
| **[YMOS](https://github.com/Evan-XYZ/YMOS)** | **打样**。指南这套思路的一次完整实现：按我自己的投资习惯抽象出来的投资文件夹，投研、策略、操盘三层，能装下你自己的策略和偏好，加阅读器和桌面客户端。下载就能用，可以照着用，也可以魔改 | 想直接拿一套搭好的，再按自己的改 |

一句话：**指南给方法，ymskill 给动作，YMOS 是照着方法搭好的一份样板。**

三样可以单独用，也能叠着用。**已经在用 YMOS 的，装上 ymskill 不用搬家**：它认得 YMOS 的目录（根目录有 `总入口暗号.md`），读 YMOS 带的 [`YMSKILL_ADAPTER.md`](https://github.com/Evan-XYZ/YMOS/blob/main/YMSKILL_ADAPTER.md) 分工；老版本 YMOS 没有这份文件，就用 [建文件夹](skills/yms-setup/references/vault-init.md) 里内置的同一份映射，并提醒你补上（桌面端做一次增量补全、拉最新的 YMOS，或者让它现在帮你补）。还没写策略 Profile、但在 `当前关注方向与投资偏好.md` 里写过目标和尺子的，它会直接读那里。

- YMOS 已经有的流程（市场洞察、我想买、头脑风暴、定时任务……）照旧用 YMOS 的；
- ymskill 补 YMOS 没有的动作：开原件核实、事件分级、跨市场传导、两把尺子、持有期复盘、回看台账、动作记录、主控心跳，产物写回 YMOS 的目录。

## 先想清楚：你赚的是哪一种钱

投资赚的是一个差：你比市场早看懂一门生意或一件事（能力圈带来的认知和时间差），市场缺钱的时候你手里有钱（流动性），价格来回摆的时候你守得住（波动）。不同的差，裁判不一样，该拿多久不一样，什么时候认错也不一样。

ymskill 管的是围绕这个差的流程：每天替你盯着市场、只告诉你什么变了；一件事值得看，就回到原件核实、把它的逻辑写清楚；用你写下的每一把尺子各量一遍；下注前过门禁；事后记账、到期回看。

它不替你决定赚哪一种差。那一项写在你的策略档案里，`/yms-setup` 会一类一类问你。说不清赚的是哪一种钱，就很难说清该用什么尺子、该拿多久。

## 装好之后能做什么

一个总入口，七段流程。每个模块是一个 Skill，模块里的每个动作是一份独立的文件，用到哪个读哪个。可以用 `/yms-watch` 这样的命令调用，也可以直接用中文说你要做什么。

### 🧭 `/yms` 总入口 · 不知道用哪个，从这里开始

- 🚪 **新手入门** — 讲清这套东西是什么、不是什么，第一次怎么走
- 🩺 **[起点诊断](skills/yms/references/start-here.md)** — 5 个问题，判断你卡在信息、策略、执行、复盘还是自动化，告诉你先用哪个动作
- 🔀 **推荐动作** — 按你说的情况，推荐 1 个主动作 + 最多 2 个辅助

### 🧱 `/yms-setup` 搭底座 · 先把你自己写下来

- 📁 **[建文件夹](skills/yms-setup/references/vault-init.md)** — 目录、给 Agent 的说明书、三份框架模板；已经有自己的笔记库，只加一段路径映射，不搬家
- 🧾 **[策略档案](skills/yms-setup/references/strategy-profile.md)** — 四问把你的每一类机会问清楚：证据、裁判、认错、信息频率，再加上你赚的是哪一种钱
- 🗂️ **[观测清单](skills/yms-setup/references/watch-setup.md)** — 看哪几个方向、信源怎么分级、什么才算变化、什么不提醒

### 🔭 `/yms-watch` 看 · 只看变化，再去开原件

- 📰 **[每日变化](skills/yms-watch/references/daily-delta.md)** — 先对昨天的待核清单，再只写实质变化；两句话压缩，事件层和「对我层」分开写
- 📶 **[事件分级](skills/yms-watch/references/event-grading.md)** — 范围、触达、持续定级别，再看阶段；资金认不认单列，不进级别
- 🔍 **[开原件核实](skills/yms-watch/references/source-check.md)** — 原件说了什么、没说什么，第一次公开是什么时候，标题和原件差在哪个词
- 🔗 **[跨市场传导](skills/yms-watch/references/transmission-map.md)** — 四段推演，用三项核查分开真映射和蹭概念

### 🧠 `/yms-think` 想 · 把尺子写下来，每一把都量一遍

- 📏 **[两把尺子](skills/yms-think/references/dual-ruler.md)** — 同一件事，用你档案里的每一把尺子各量一遍，分别给结论，再判断它更像哪一类
- 🏛️ **[核心资产七问](skills/yms-think/references/core-asset-7q.md)** — 判定卡 + 看空反证清单；答不上来标存疑（我的样本模具，可改）
- 🧮 **[反向 DCF](skills/yms-think/references/reverse-dcf.md)** — 不问值多少钱，只倒推当前市值隐含了多高的增长要求；带计算脚本
- 🎙️ **[财报叙事](skills/yms-think/references/earnings-narrative.md)** — 对比两个季度的管理层口径：承诺兑现、叙事转移、问答回避；拿不到原文就不做

### 🚪 `/yms-gate` 做 · 门禁在真下注时出场

- 🛑 **[买入门禁](skills/yms-gate/references/buy-gate.md)** — 四问：动机、审计、时机、这笔是哪类交易打算拿多久；答不清就亮红灯
- ↩️ **[卖出对照](skills/yms-gate/references/exit-check.md)** — 想卖的时候，把你当初的买入理由和认错条件原文摆回来
- 🖥️ **[操盘台](skills/yms-gate/references/trading-desk.md)** — 生成一个单文件的本地操盘台：决策台 + 计划台，门禁写死在工具里，不联网

### 📒 `/yms-review` 回看 · 复盘不靠自觉，靠记账

- ⏳ **[持有期复盘](skills/yms-review/references/holding-period-review.md)** — 交割单按持有期分组，看钱到底赚在哪一组、亏在哪一组；带配对脚本
- 🚩 **[三红旗](skills/yms-review/references/red-flag-scan.md)** — 机械扫放宽止损、亏损加仓、绕过门禁；赚钱的违规一样上榜
- ⚖️ **[单笔归因](skills/yms-review/references/beta-alpha-attribution.md)** — 跑赢板块没有、逻辑兑现没有、涨的是业绩还是估值、能不能复制
- 📊 **[回看台账](skills/yms-review/references/research-ledger.md)** — 系统推过的每个方向都登记，7 / 30 / 60 天后对比基准
- 🔒 **[规则变更](skills/yms-review/references/rule-change-review.md)** — 不管是你想改还是 AI 提议改，都过同一道门槛

### 💭 `/yms-brainstorm` BrainStorm · 想法不过夜，做过的事也不过夜

三层，加一层底：原始想法 → Insight → 状态机，底下一层长期记忆。回看记的是机器的账，这里存的是你的想法、感悟和复盘心得；两边合起来，系统才会越用越像你。

- 🎤 **[记下来](skills/yms-brainstorm/references/capture.md)** — 「开始今天的头脑风暴」先读你的长期记忆和当前状态再开聊；「帮我记下来」直接存。原话按说话顺序存，不美化
- 🧩 **[整理](skills/yms-brainstorm/references/insight.md)** — 拆成事实 / 解释 / 假设 / 情绪；假设写清对了会看到什么、错了会看到什么；主线是你的原话
- 🛠️ **[动作记录](skills/yms-brainstorm/references/action-log.md)** — 今天真的做了什么：读了哪份原件、跑了哪个流程、改了哪条规则、在哪一步犹豫了
- 🏺 **[沉淀](skills/yms-brainstorm/references/distill.md)** — 一条感悟该去哪：长期记忆、短期灵感、长期框架、执行清单，还是走规则变更；你确认才写
- 🧭 **[状态机与回看](skills/yms-brainstorm/references/status-review.md)** — 刷新当前状态；每周对照想法和动作、给到期的假设对真值；月度总结
- 🗃️ **[历史资料入职](skills/yms-brainstorm/references/history-onboarding.md)** — 把多年的旧日志做成索引和阶段梳理，不改原文，不直接变成规则

### 🤖 `/yms-autopilot` 自己跑 · 我每天只批示

- ⏰ **[定时任务](skills/yms-autopilot/references/schedule-task.md)** — 把一条手动跑稳的流程写成任务说明；任务多了合成一张按依赖排的调度表
- 💓 **[主控心跳](skills/yms-autopilot/references/heartbeat.md)** — 每天读完所有产物，写一份交接，只把需要你拍板的事交给你

## 开始使用

### 第一次：先了解入口

```text
/yms 新手入门
```

### 不确定该用什么：让 `/yms` 推荐

把你现在的情况写在 `/yms` 后面，说得不完整也没关系：

```text
/yms 我做了五六年 A 股，收盘复盘时想得很清楚，第二天盘中又总是冲动开仓。我该先从哪里补？
```

### 已经知道要做什么：直接调用模块

```text
/yms-setup 帮我在 ~/投资 下面建投资文件夹，然后写第一版策略档案。
```

```text
/yms-watch 今天什么变了
```

```text
/yms-gate 我想买一只半导体设备股，计划仓位 8%，帮我过一遍门禁。
```

```text
/yms-review 附件是我今年的交割单，按持有期复盘一下。
```

用 Claude Code 插件装的，命令会带命名空间，例如 `/ymskill:yms`、`/ymskill:yms-gate`。

### 收到结果之后

结果需要补充，直接在当前对话里给新的事实或材料，当前模块接着做。这件事做完、有了新目标，再说一次 `/yms`。所有产物都写回你的文件夹，换一个对话、换一个 Agent 也接得上。

## 怎样提供材料

结果取决于你的文件夹里写了什么、你给了什么材料。不用为了填满模板去回答无关的问题：

| 模块 | 开工前文件夹里要有 | 这次你可以给它 |
|:---|:---|:---|
| `/yms-setup` | 一个放文件夹的位置 | 你的投资经历；有成交记录的话一起给，用来对照你说的话 |
| `/yms-watch` | 观测清单 | 今天看到的新闻、链接；它能联网的话会自己去找原件 |
| `/yms-think` | 策略档案（至少一个目标和它的尺子） | 公司的财报、电话会原文、你的想法 |
| `/yms-gate` | 策略档案、长期规则 | 标的、买入理由、止损价、仓位（用百分比） |
| `/yms-review` | 交易记录或券商导出的交割单（先删掉账户号、姓名） | 当初的买入理由、要对比的基准 |
| `/yms-brainstorm` | 什么都不用，第一次用会建长期记忆和状态机 | 随手说的话、语音转文字；旧日志放进 `历史资料/原始资料/` |
| `/yms-autopilot` | 至少一条手动跑满三期的流程 | 每条流程的产物放在哪 |

## 安装

选和你的 Agent 相符的一种。下面的命令在终端里运行，不要当聊天内容发给 Agent。

### 用 Skills CLI 装到你电脑上已有的 Agent

终端要能运行 `npx`（装了 Node.js 就有）：

```bash
npx -y skills add Evan-XYZ/ymskill -g -y --skill '*'
```

- `-g` 装到用户级目录，所有文件夹里都能用；`--skill '*'` 装全部 8 个模块；`-y` 不再逐项确认。
- 它会自动找到你电脑上已经装了的 Agent（Claude Code、Codex、Cursor、OpenClaw、Hermes、Gemini CLI 等），只装到这些里面。Codex、Cursor、Gemini CLI 这类读通用目录 `~/.agents/skills/` 的共用一份，Claude Code 会连到同一份。
- 只装到某一个 Agent，把 `-y` 去掉按提示选，或者写明：`--agent claude-code`。
- **不要加 `--all`**：它会给 Skills CLI 认识的几十个 Agent 都在你的用户目录下建一个文件夹，不管你装没装那个 Agent。

### 用 Claude Code 插件市场

```bash
claude plugin marketplace add Evan-XYZ/ymskill
claude plugin install ymskill@ymskill
```

装完以后命令带 `ymskill:` 命名空间：总入口是 `/ymskill:yms`，买入门禁所在的模块是 `/ymskill:yms-gate`。

### 手动复制

```bash
git clone https://github.com/Evan-XYZ/ymskill.git
cp -R ymskill/skills/yms* ~/.claude/skills/
```

- 上面是 Claude Code 的用户级目录；只想在某个文件夹里用，复制到 `<那个文件夹>/.claude/skills/`。Codex 放进 Codex 的 Skills 目录。
- 复制整个模块文件夹，里面的 `references/`、`templates/`、`scripts/` 都要带上。

### 只能对话的工具

ChatGPT、Claude、Gemini、豆包、DeepSeek、Kimi 这类只能对话的工具，没有 Skills 机制也能用：打开要用的那一份动作文件（`skills/<模块>/references/<动作>.md`），把正文整个复制进对话，再把它要读的文件（比如你的策略档案）一起贴进去。没有定时任务，就每天手动跑同一条，一样能积累。

### 装了什么

```text
skills/
├── yms/             总入口：新手入门、起点诊断、推荐动作
├── yms-setup/       搭底座：建文件夹 · 策略档案 · 观测清单（附文件夹模板）
├── yms-watch/       看：每日变化 · 事件分级 · 开原件核实 · 跨市场传导
├── yms-think/       想：两把尺子 · 七问 · 反向 DCF（附脚本）· 财报叙事
├── yms-gate/        做：买入门禁 · 卖出对照 · 操盘台
├── yms-review/      回看：持有期复盘（附脚本）· 三红旗 · 单笔归因 · 回看台账 · 规则变更
├── yms-brainstorm/  BrainStorm：记下来 · 整理 · 动作记录 · 沉淀 · 状态机与回看 · 历史资料入职（附模板）
└── yms-autopilot/   自己跑：定时任务 · 主控心跳
```

Agent 平时只看到每个模块的名字和一两句描述，你用到哪个动作，它才读那一份文件。不需要 API Key，不需要券商账户权限。

### 装完没看到命令

先确认安装命令成功了，装到的是你正在用的那个 Agent。Skills CLI 和手动复制用短命令（`/yms`）；Claude Code 插件用带命名空间的命令（`/ymskill:yms`）。实在找不到，直接用中文说你要做的事，Agent 会按描述找到对应的模块。

各平台的细节见 **[docs/安装与使用.md](docs/安装与使用.md)**。工具每个月都在变，以官方最新版本为准。

## 从哪开始

不用 7 个模块都用。按你现在的处境找起点，一次只加一个：

| 你的处境 | 卡在哪 | 先用 |
|:---|:---|:---|
| 刚装好，想先看看它能干什么 | 不想先填一堆东西 | `/yms` 先试一下：有交割单 → 持有期复盘；有一条新闻 → 开原件核实；正想买 → 买入门禁 |
| 对 AI 好奇，还没有成形的策略 | 每天被快讯淹没 | `/yms-setup` 建文件夹 → 观测清单 → `/yms-watch` 每日变化 |
| 有几年实盘、有判断，但散在脑子里 | 每研究一家公司都像从头来 | `/yms-setup` 策略档案 → `/yms-think` 两把尺子 |
| 策略清楚，执行变形 | 收盘想明白，盘中又冲动 | `/yms-gate` 买入门禁 → 卖出对照 → 操盘台 |
| 经历过牛熊，有成交记录 | 复盘容易自欺，一亏就想改规则 | `/yms-review` 持有期复盘 → 三红旗 → 规则变更 |
| 想法和复盘散在聊天记录和备忘录里 | 想过的总是找不到，隔一阵又信回去 | `/yms-brainstorm` 记下来 → 整理 → 每周回看 |
| 流程多到按不过来 | 按按钮的人成了瓶颈 | `/yms-autopilot` 定时任务 → 主控心跳 |

**自动化永远放在最后。** 哪条流程手动跑顺了、至少跑过三期，再交给定时任务。前面没跑顺，自动化只会把混乱也自动化。

## 更新

在 Agent 里说：

```text
/yms 更新
```

或者用你当初装的方式再装一次：Skills CLI 再跑一次安装命令；Claude Code 插件用 `claude plugin update ymskill@ymskill`；手动复制的，在仓库目录里 `git pull`，再复制一次。

更新只换 Skills，**你的投资文件夹一个字不动**。你自己改过某个动作文件的，更新前先备份那一份。

## 三个提醒

1. **框架可以借，策略是你自己的**。用在什么市场、什么标的上，是你的决定；
2. **AI 不做买卖决策**。真正的买卖和资金风险，永远由你自己承担；
3. **保护你的数据**。账户密码、完整持仓、API Key 不交给不信任的云端服务；向云端模型提问时，资金量用百分比，不写金额。
