# 观测清单 · watch-setup

> 差别不在工具，在于你有没有提前定义清楚：什么算变化、什么值得看、看完要核什么。定义清楚了，AI 才能替你守着；定义不清，AI 只会帮你把焦虑放得更大声。
> 来自《AI 投资指南》03 投研层 §一–三 · §五 · §七
>
> 属于 `yms-setup` 模块。也可以单独把这份复制进任何 AI 对话里用。

## 它做什么，不做什么

- 做：帮你定下看哪几个方向、四个维度各看什么、信源怎么分级、什么才算变化、什么不提醒，生成一份 `观测清单.md`。每日变化（`yms-watch`）只按这份清单干活。
- 不做：不替你挑板块，不推荐信源以外的任何东西，不把它做成分时盯盘。目标是让你少看屏幕，不是看得更频繁。

## 前置检查

| 要读 | 默认路径 | 用来做什么 | 缺了怎么办 |
|:---|:---|:---|:---|
| 策略档案 | `01_我的投资框架/Strategy_Profile.md` | 每一类机会「需要多快的信息」决定观测频率；能力圈决定关注方向 | 没有不阻断，但提醒我：关注方向最好从能力圈出发，先跑 `strategy-profile` 更顺 |
| 观测清单 | `01_我的投资框架/观测清单.md` | 已有就进「修订」 | 没有就从头问 |

## 步骤

一次问一节，等我答完再往下。

**1. 关注方向**
你想盯哪 3–8 个板块或主题？颗粒度放在板块和方向，不必每天挖个股。方向越多噪音越大，超过 8 个提醒我砍。

**2. 四个维度，各看什么**

| 维度 | 问我 |
|:---|:---|
| 宏观与板块 | 全市场量能、利率、波动率，你看哪几个？怎么判断主线有没有换？ |
| 基本面拐点 | 财报 / 指引、提价、大订单、扩产、关键原材料、政策，哪些对你的方向最要紧？ |
| 催化事件日历 | 未来 4 周有哪些确定性事件（议息、CPI、核心公司财报、行业大会）？ |
| 价格行为与趋势阶段 | 新高 / 新低、放量突破、跌破关键位置；你用什么判断一个板块处在新高、新低、底部震荡还是顶部震荡？ |

第四个维度提醒我一句：少讲单日涨跌归因，多看大趋势阶段。「某天涨 8% 是因为某条消息」经常归错，就算归对了，几天就失效。

**3. 信源：只回答一个问题——这句话是谁说的**

把我列的信源逐个分级：

| 级别 | 是谁 | 能怎么用 |
|:---|:---|:---|
| S · 官方一手 | 监管机构、央行、统计局、交易所公告、公司 IR、财报、当事人原帖 | 可以当事实 |
| A · 权威一手媒体 | 一线财经媒体的独家报道、研究机构自己整理的数据 | 可以当事实，但写「据 X」 |
| B · 二手 | 转述、评论、自媒体、研报观点、系统自己的聚合摘要 | 不当事实，只当「有这个说法」 |

- 媒体当闹钟，不当货源。大多数信源都会是 A 或 B，这很正常。
- 每个信源记「最近一次成功」和「连续失败」，连续失败 3 次标红。
- 提醒我管源，不只加源：一个源刷屏（比如一天塞进来上千条、占了大半条目），会把有分量的源稀释掉，要限流或换掉。

**4. 什么才算变化，什么不提醒**
默认的变化：S / A 级事件（不管打没打到我关注的东西）、趋势阶段换档、关键位置被打破。问我还要加什么、要不提醒什么。

**5. 选股问句模板库（只有用自然语言选股工具才需要）**
- 别让 Agent 现编查询。先手动把工具的能力边界测清楚，沉淀成问句模板库，Agent 只能从库里选。
- 模板按行情场景分：趋势延续 / 启动初期 / 修复反弹 / 退潮 / 事件脉冲。先判风格，再选模板。
- 每次查询过「数据六检」：

| 检查项 | 查什么 | 常见陷阱 |
|:---|:---|:---|
| 市场环境 | 大盘处在什么状态 | 破位环境里的「逆势突破」很多是假的 |
| 语义对齐 | 工具的指标口径和你的本意一致吗 | 「净利润增长」有没有含非经常性损益 |
| 字段完整 | 行业、换手、估值字段齐不齐 | 缺字段导致后面的归因失真 |
| 日期有效 | 抓到的是你要的那一天吗 | 数据还没更新就去抓，拿到的是昨天 |
| 样本完整 | 是否剔除 ST、退市风险、流动性太差的 | 掉进流动性陷阱 |
| 正反样本 | 同类形态在当前周期里的成功率 | 震荡市别机械套用强势市场的打法 |

选出来的结果不等于买点，只触发一个「值得研究」的任务。

**6. 生成**
按 `templates/观测清单.md` 起草，给我看，我说「确认」才写入。

## 输出

- 写到：`01_我的投资框架/观测清单.md`。
- 对话里附一句：这份清单下，每日变化大概会看哪几个信源、多久跑一次。

## 红线

- 不替我挑板块，不荐股。
- 信源级别按「这句话是谁说的」定，不按「这家媒体有多权威」定。
- 没有我的「确认」，不写入 `01_我的投资框架/`。

## 我自己的样本

我的系统里有近 30 个信源，其中二十多个是媒体，当事方自己发的原文只有一个。早期一天只真抓几次，大部分时间读的是缓存；改成每小时真抓一轮之后，从文章发布到进入系统的中位时间从约 381 分钟降到约 28 分钟。代价是噪音也跟着变多，第一周就发现一个批量生成快讯的源占了全部条目七成。

另一个调整是范围：我的投研层现在盯板块和方向，不去每天挖个股。维度不变，颗粒度变粗了，噪音少了一大截。
