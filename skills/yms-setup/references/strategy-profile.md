# 策略档案 · strategy-profile

> AI 读不了你的脑子，只读得了你写下来的东西。这一步把你的每一类机会问清楚：靠什么证据、谁是裁判、什么时候认错、你赚的是哪一种钱。
> 来自《AI 投资指南》04 策略层 §一–四 · 可带走资产 1
>
> 属于 `yms-setup` 模块。也可以单独把这份复制进任何 AI 对话里用。

## 它做什么，不做什么

- 做：当一个中立、严格的策略架构师，按类别把你的策略问清楚，找出回答里互相打架的地方，生成一份 `Strategy_Profile.md`。其余模块里的两把尺子、门禁、卖出对照、复盘，全都读这份。
- 不做：不推荐股票，不评价你能不能赚钱，不替你选流派，不替你定仓位、止损和持有期。

## 前置检查

| 要读 | 默认路径 | 用来做什么 | 缺了怎么办 |
|:---|:---|:---|:---|
| 策略档案 | `01_我的投资框架/Strategy_Profile.md` | 已经写过的就进「修订」：先把现有内容摆出来，问我改哪一节 | 没有就从头问 |
| 长期规则 | `01_我的投资框架/长期规则.md` | 交叉审查时对照红线 | 没有不阻断 |
| 交易记录或复盘 | `04_决策与交易记录/` `05_复盘/持有期复盘_*.md` | 有的话，用我真实的成交去对照我说的话 | 没有不阻断 |

## 步骤

每次只问 1–2 个问题，等我回答再继续。

**1. 机会分类**
你平时做的交易，是一类还是几类？（例如：长拿的核心资产 / 几周的事件波段 / 短线）
- 不止一类，后面每一步都按类别分别问，每一类单独一节。
- 有成交记录的，提醒我对照：你的钱实际赚在、亏在哪个持有期？有没有一类交易你一直在做，却从来没写下来？

**2. 每一类：四问**

| 问 | 问什么 | 答到什么程度才算清楚 |
|:---|:---|:---|
| 主要证据 | 这一类你做决策主要靠什么？ | 财报 / 行业景气 / 价格形态 / 事件，选得出主次 |
| 谁是裁判 | 最后谁说了算你对还是错？ | 基本面有没有被证伪 / 市场价格 / 事件是否兑现，只能选一个主裁判 |
| 何时认错 | 什么具体条件出现，你承认看错、离场？ | 能被判断的条件。「看情况」「跌多了」不算 |
| 信息频率 | 这一类你需要多快的信息？你实际看盘的频率和它匹配吗？ | 季度 / 每天 / 实时，并说出实际频率 |

**3. 每一类：你赚的是哪一种钱**
投资赚的是一个差。这一类机会里，你赚的主要是哪一种？
- 能力圈带来的认知和时间差：你比市场早看懂一门生意或一件事；
- 流动性：市场缺钱、被迫卖的时候你手里有钱；
- 波动：价格来回摆，你守得住纪律；
- 说不清。

「说不清」可以照实写。但要提醒我：说不清赚的是什么钱，就很难说清该用什么尺子、该拿多久。

**4. 每一类：尺子**
把这一类机会的判断标准写成 3–5 条**逐条可以回答**的问题。用我的原话，不替我写。
- 我写不出来时，可以把下面的坐标表拿给我参考，但不替我选：

| 代号 | 策略结构 | 裁判是谁 | AI 在这里主要干什么 |
|:---:|:---|:---|:---|
| S1 | 价值 / 均值回归 | 基本面证伪与否 | 估值压力测试、反向 DCF、看空清单 |
| S2 | 成长 / 质量 | 兑现节奏有没有掉队 | 财报季度追踪、叙事一致性审查、七问审计 |
| S3 | 趋势 / 动量 | 市场价格 | 条件选股、新高跟踪、Beta / Alpha 归因 |
| S4 | 事件驱动 | 预期差有没有兑现 | 传导链推演、产业链供需瓶颈测算 |
| S5 | 短周期 / 微观 | 执行点与流动性 | 执行纪律、滑点控制 |
| S0 | 跨结构通用 | 你自己定的规则 | 入场定性、买卖门禁、红旗审计 |

**5. 每一类：风险与仓位**
- 单只仓位上限是多少（用百分比）？
- 亏损时允不允许加仓？什么前提下允许（只允许事先写好的分批计划）？
- 打算拿多久？
- 什么**不算**认错的理由？（例如：一两个季度的股价波动 / 一两天的分时噪音）

**6. 交叉审查**
逐条检查我的回答，有就直接指出来，引用我的原话：
- 有没有逻辑冲突？例如：用短线形态入场，却用长线基本面死扛；
- 有没有用 A 类机会的裁判，去评判 B 类机会？举出我回答里可能出现这种情况的地方；
- 有哪一类机会，我能说出来、但从来没写成文字的判断标准？列出来让我补写；
- S0 那一层（止损不放宽、亏损加仓只允许事先的分批计划、绕过门禁要留记录）我认不认？认的话，确认它们在 `长期规则.md` 的红线里。

**7. 坐标与先建哪一层（可选）**
两道自测题，帮我看主导流派：
1. 买入后跌了 20%，你的第一反应是——A. 到击球区了，准备加仓；B. 纪律破了，先走；C. 回去看事件还在不在发酵、预期差还在不在。
2. 你最爱看哪类信息——A. 财报和深度研报；B. K 线、量价、板块强弱；C. 突发新闻、政策、机构动向。

偏 A 先建策略层（`yms-think`），偏 B 先建操盘层和投研层（`yms-gate`、`yms-watch`），偏 C 先建投研层（`yms-watch`）。混合型就把每一类分开，各自过四问、各自配尺子。

**8. 生成**
按 `templates/Strategy_Profile.md` 的结构起草，每一类机会单独一节。没回答的字段保留 `【待填】`。把草稿完整给我看，我说「确认」才写入，并把「最后确认」改成今天的日期。

## 输出

- 写到：`01_我的投资框架/Strategy_Profile.md`（修订时只改我确认的那几节，其余不动）。
- 在对话里另附一段「这次没写清的地方」：哪些字段还是 `【待填】`、交叉审查查出的冲突我选择暂时保留的有哪些。

## 红线

- 不给买卖建议，不预测涨跌，不评价我的策略能不能赚钱。
- 不替我定参数。我问「仓位上限多少合适」，回答：这一项只能你自己定，我可以帮你对照你过去的成交和你写下的风险承受方式。
- 不用常识补我没说的尺子。补出来的只会是一把四平八稳、量什么都差不多的通用尺子。
- 没有我的「确认」，不写入 `01_我的投资框架/`。

## 我自己的样本

我现在的投资收敛成两个目标，各配一把尺子：

| 问题 | 目标一：核心资产 | 目标二：势能波段 |
|:---|:---|:---|
| 主要证据 | 能力圈内看得懂的业务、稀缺卡位、终局空间 | 已经发生的强事件（读过一手原件）+ 资金的反应 |
| 谁是裁判 | 卡位和终局假设有没有被证伪 | 势能有没有在传播、资金认不认 |
| 何时认错 | 卡位丢了、终局假设坍塌 | 动手前就写好的失效条件被触发 |
| 信息频率 | 季度财报、产业链变化 | 天级，窗口是几周 |
| 尺子 | 能力圈 · 稀缺卡位 · 终局 · 势能阶段 · 股性 | 催化真不真 · 资金认不认 · 阶段早不早 · 标的纯不纯 · 失效条件 |

这张表不是我当初一条条写好的，是回头补写的。补的过程本身就在照出哪里以前没写清：第二把尺子一直在我脑子里、在我的交易习惯里，但没写成文字，所以 AI 只能拿第一把尺子去量所有东西。这是一个样本，你的分类可以完全不一样。

想做一次更完整的结构体检，可以用开源的 `ymos-diagnosis`，思路是一样的。
