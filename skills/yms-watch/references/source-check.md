# 开原件核实 · source-check

> 每转一手，限定词就掉一层。媒体当闹钟，不当货源；一件事值得看，就回到原件。
> 来自《AI 投资指南》03 投研层 §二 · 可带走资产 ②
>
> 属于 `yms-watch` 模块。也可以单独把这份复制进能联网的 AI 对话里用。

## 它做什么，不做什么

- 做：找到一件事的一手原件，对着原件写清「说了什么」和「没说什么」，查它第一次公开的时间，最后用一句话指出新闻标题和原件差在哪个词。
- 不做：不判断这件事利好谁，不编链接，不拿记忆里的内容冒充原件。

## 前置检查

| 要读 | 默认路径 | 用来做什么 | 缺了怎么办 |
|:---|:---|:---|:---|
| 要核的事 | 我贴的新闻、链接，或每日观测里的一条 | 核实对象 | 只有一句转述时，先问我在哪看到的 |
| 核实记录 | `03_每日观测/核实记录/` | 同一件事核过没有 | 核过就在原文件后面追加，不另开 |

## 步骤

**1. 写清要核的核心事实**
一两句话：这条新闻声称发生了什么。核的是这一两句，不是整篇报道。

**2. 找一手原件**
监管文件 / 官方新闻稿 / 公司公告 / 财报 / 法案文本 / 当事人原帖。
- 给出你**实际打开过**的链接；
- 原件是 PDF、读不出文字 → 换同一份文件的其他官方版本再试：交易所或巨潮资讯的公告页、公司 IR 页、监管机构网页版；
- 还是打不开（被拦、还没发布、要登录）→ 写「未核到一手（原因）」，降低这件事的确定性，不硬凑。转载这份原件的媒体页面算 A 或 B，不算一手。

**3. 按三种情况处理**

```text
① 有公开原件        → 必须开一次，以原件为准；媒体说法和原件有出入，写一句出入在哪
② 媒体独家、无原件  → 标「媒体独家，无公开原件」，这件事最高按 A 级处理
③ 系统自己算出的信号 → 以原始数据表为准，不用下游的摘要句
```

**4. 第一次公开是什么时候**
原件的发布日期和新闻的日期对一下。原件早已发布、之前已被报道过的，标「旧闻翻新」，写清第一次公开的日期。

**5. 两栏对照**
- **原件说了什么**：逐条保留限定词——期限、适用对象、上限、条件、生效日、是否还在征求意见；
- **原件没说什么**：新闻里有、原件里没有的说法（「利好谁」「给谁带来什么」），单独列出，每条戴上帽子「据 X 分析，原件无此表述」。

**6. 转了几手（能查就查）**
原件 → 第一篇报道 → 转述 → 你看到的这条。每一手掉了哪个限定词。

**7. 一句话对比**
新闻标题的说法和原件之间，差在哪个词。

**8. 回头修正分级**
按 `event-grading` 给定评；和初评不同，写一句改判理由。

## 输出

写到 `03_每日观测/核实记录/YYYY-MM-DD_<事件简称>.md`：

```markdown
# 核实：<事件简称>
> 核实日期：YYYY-MM-DD · 结论：已核到一手 / 媒体独家无原件 / 未核到一手（原因）

## 核心事实（新闻声称）
……

## 原件
- 链接：<实际打开过的>
- 发布方 / 发布日期：……
- 第一次公开：YYYY-MM-DD（旧闻翻新：是 / 否）

## 原件说了什么
- ……（原件位置：第 X 页 / 第 X 节）

## 原件没说什么
- 据 X 分析，原件无此表述：……

## 转了几手
原件 → …… → ……（每一手掉了什么）

## 标题和原件差在哪个词
「……」 vs 「……」

## 定评
势能：……（初评 → 定评，改判理由：……）
```

## 红线

- 不编链接，不凭记忆写「原件内容」。
- 引原件只摘短句并标位置，不整段搬运。
- 「原件没说什么」那一栏必须戴帽子，不能和原件内容混写。
- 不给买卖建议。

## 我自己的样本

9 月中旬 SEC 发了一份关于代币化的**有条件豁免令**。几天后我回头查，这件事在我自己的系统里转了四手：原件 → 媒体 → 我的市场全景报告 → 下游报告里的「补充」一行 → 最后我口头说出来变成了「通过了美股代币化」。那几天的报告里，SEC 官网链接一次都没出现过。「有条件豁免」和「批准」差得很远，而每转一手，限定词就掉一层。

我的近 30 个信源里，当事方自己发的原文只有一个。所以开原件这一步不能靠信源，只能靠规矩。
