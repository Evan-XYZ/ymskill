# 事件分级 · event-grading

> 闹钟每天报出几百条，开原件又费时间，那先开哪件？需要一把不看你持有什么、只看事件本身有多大分量的尺子。
> 来自《AI 投资指南》03 投研层 §四 · 可带走资产 ①
>
> 属于 `yms-watch` 模块。也可以单独把这份复制进任何 AI 对话里用：每天把看到的重要新闻丢给它。

## 它做什么，不做什么

- 做：对每一件事，按范围、触达、持续三个维度定级别（S / A / B / C），再标阶段；资金认不认单列。S / A 级事件登记下来，留着以后回头对结果。
- 不做：不看你的持仓定级别，不把「涨了」当成「重要」，不给买卖建议。

## 前置检查

| 要读 | 默认路径 | 用来做什么 | 缺了怎么办 |
|:---|:---|:---|:---|
| 事件本身 | 我贴的新闻、链接，或每日观测里的一条 | 定级的对象 | 只有一个标题时，先问我有没有原文或链接 |
| 核实记录 | `03_每日观测/核实记录/` | 有原件核实的，按原件定评 | 没有就只做初评 |
| 事件登记 | `03_每日观测/事件登记.md` | 同一件事登记过没有 | 不存在就新建 |

## 步骤

**1. 来源级别**
S（当事方原文：监管、央行、统计局、交易所、公司公告 / 财报）/ A（一线媒体独家、机构自有数据）/ B（转述、评论、自媒体、摘要）。
核心事实只有 B 级来源 → 事件最高按 B 处理；只有 A 级 → 表述保留「据 X」。

**2. 三个维度定级别**

| 维度 | 问什么 | 档位 |
|:---|:---|:---|
| 范围 | 打到多大？谁的生意变了，变了几层 | 行业 / 跨链（新赛道被承认、规则改写、平台级产品）· 子链（一条产业链的格局变了）· 单公司 · 噪音 |
| 触达 | 多少人会知道，会不会变成共识叙事 | 出圈（大众媒体、热搜、散户社区大量讨论、普通人开始用）· 圈内（行业媒体、研报密集、行业 KOL 在讨论）· 小众（原件发了没人转述） |
| 持续 | 影响多久 | 数月（制度改写、平台级产品、资本开支周期）· 数周（订单、财报季、政策落地过程）· 数天（一次性新闻、情绪） |

- 触达不用做得很重，查一两个信号就够：短视频平台的搜索联想有没有出现、社区讨论量、新闻条数。写明看了哪个。
- 持续看日历上有没有排着后续里程碑（生效日、量产日、财报日），列出来；没有就写没有。

| 级别 | 条件 |
|:---|:---|
| **S · 行业地震** | 范围 = 行业 / 跨链，持续 = 数月，触达至少圈内 |
| **A · 强势能** | 子链级且持续数周以上；或行业级但只持续数周 / 只在小众 |
| **B · 中势能** | 单公司基本面增量、季度级信号，数天到数周 |
| **C · 噪音** | 其余，一周内衰减 |

**3. 阶段**
🌱 刚起 · 🌿 发酵 · 🍂 成熟 · 🧊 退潮。依据写清：相关板块近 20 日走势、是否已经大面积报道。

**4. 资金认不认：单列，不进级别**
✓ / 待看 / ✗。看的信号：相关主题放量、站上中期均线的比例在升、新高名单里出现同主题。
级别说的是事件的**潜在**势能；资金认不认是**事后确认**。两件事混在一起，就会变成「涨了所以重要」的循环论证。

**5. 下一步**
只用 看 / 核 / 等 / 对照 写一句。S / A 级的下一步默认是「核：开原件」（`source-check`）。

**6. 初评和定评**
- 只看了媒体报道 → 初评；
- 开过原件之后 → 定评。改判时写一句为什么。

## 输出

每件事一行：

```text
势能：<级别> · 范围 <> · 触达 <>（依据：<信号>）· 持续 <>（里程碑：<>）· 阶段 <> · 资金 <> ｜来源 <级别> ｜初评/定评 ｜下一步：<>
```

判不了的维度写「待看」，不要硬凑。

S / A 级事件，在 `03_每日观测/事件登记.md` 末尾追加一行（文件不存在就按下面的表头新建）：

```markdown
# 事件登记
> 只追加，不改旧行。分级卡在校准期，每一行都是假设；回看由 yms-review 的回看台账来做。

| 登记日 | 事件 | 级别 | 范围 · 触达 · 持续 | 阶段 | 资金 | 来源级别 | 原件 | 初评/定评 |
|:---|:---|:---|:---|:---|:---|:---|:---|:---|
```

定评和初评不同时，追加一行新的，写「定评，改判理由：……」，不改原来那一行。

## 红线

- 级别只看事件本身，不看我持有什么。
- 资金认不认不进级别。
- 这张卡还在校准期，是假设，不是结论；不要把级别说成「信号」。
- 不给买卖建议。

## 我自己的样本

这张卡是一次错过之后加的。9 月中旬一份和资产代币化有关的监管文件，我的系统看见了，也开了原件，但当时判断值不值得跟，问的主要是「它跟我的持仓、关注方向、能力圈甜区有没有关系」，结果被标成「只作观察」。随后一只代币化概念的小票连续大涨。缺的就是一把只看事件本身有多大分量的尺子。

我给自己定的用法（样本，可改；你的用法写进观测清单）：

| | 🌱 刚起 / 发酵早期 | 🌿 发酵中段 | 🍂 成熟 | 🧊 退潮 |
|:---|:---|:---|:---|:---|
| S / A | 当天认真研究：催化真不真、资金认不认、阶段早不早、标的纯不纯、什么情况下算错 | 找还没传到的那一层 | 错过第一波可以接受，不追高 | 只看不追；对已有的东西是风险提示 |
| B | 进研究队列 | 记一行 | 记一行 | 不写 |
| C | 不推演 | | | |

每个 S / A 事件我都登记，8 周后回头看：S 级之后 30 / 60 天的表现是不是明显强于 A、A 强于 B，判「数月」的有没有真持续。对不上就改维度或阈值。到目前为止 S 级登记后的整体表现比 A 级好，但样本很少，我只当线索，不当信号。
