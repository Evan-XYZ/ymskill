# 看 · yms-watch

> 信息分两层：闹钟负责不漏，原件负责不错；中间只有「变化」值得你花注意力。
> 来自《AI 投资指南》03 投研层

## 这个模块里有什么

| 你说 | 做什么 | 读 |
|:---|:---|:---|
| 「今天什么变了」「跑一下每日观测」 | 先对昨天的待核清单，再只写实质变化；两句话压缩，事件层和「对我层」分开写 | `references/daily-delta.md` |
| 「这件事有多大分量」「分个级」 | 按范围、触达、持续定级别，再看阶段；资金认不认单列，不进级别 | `references/event-grading.md` |
| 「核实一下」「找原件」 | 找到一手原件，写清原件说了什么、没说什么，标题和原件差在哪个词 | `references/source-check.md` |
| 「会传导到哪」「是不是蹭概念」 | 四段推演，用三项核查分开真映射和蹭概念 | `references/transmission-map.md` |

只读对应的那一份；它点名要用的另一份（比如开原件核实最后按事件分级定评），用到时再读。四个动作的接法：

```text
每日变化 ──给每条信号初评──→ 事件分级（初评）
                                │ S / A 级
                                ▼
                           开原件核实 ──回头修正──→ 事件分级（定评）
                                │ 有跨市场传导
                                ▼
                            跨市场传导
```

分级决定开不开原件，核实的结果再回头修正分级。

## 开工前（四个动作共用）

1. 先认文件夹：根目录有 `总入口暗号.md` 的是 YMOS，说明书换成根目录的 `YMSKILL_ADAPTER.md`（没有就用 `yms-setup` 建文件夹里内置的 YMOS 映射；策略档案按映射找不到时，照内置映射里的兜底再找一遍，适配页是旧版的也照做），下面各步的路径一律按映射换，按本节末尾「在 YMOS 文件夹里」办，不当成没初始化。其他文件夹读说明书（`AGENTS.md` / `CLAUDE.md`）和里面的「路径映射」。
2. 读 `01_我的投资框架/观测清单.md`：关注方向、信源和级别、什么才算变化。文件在但只有占位、没填关注方向的空模板，算缺。每日变化缺了它就停，提示先跑 `yms-setup` 的观测清单；另外三个动作缺了它可以跑，但输出里写明「无观测清单对照」。
3. 要写「对我层」时才读 `Strategy_Profile.md`。

**没有投资文件夹时**：开原件核实、事件分级照跑，结果先给在对话里；需要存文件的（比如整理好的交割单），放进当前目录的 `ymskill_试用/`。结束时问要不要建文件夹（`yms-setup`），把结果挪进去。其余动作先提示建文件夹。

**在 YMOS 文件夹里**（根目录有 `总入口暗号.md`）：每日变化交给 YMOS 的「跑一下市场洞察」「跑一下投资雷达」；事件分级、开原件核实、跨市场传导照常做，产物写到 `Eyes/事件登记.md`、`Eyes/核实记录/`、`Eyes/传导推演/`，观测清单读 `持仓与关注/当前关注方向与投资偏好.md`（以根目录 `YMSKILL_ADAPTER.md` 为准；没有这个文件就按 `yms-setup` 建文件夹里的 YMOS 映射）。

## 这个模块的规矩

- **信源三级**：S 官方一手 / A 权威一手媒体 / B 二手。核心事实只有 B 级来源的，这件事最多当 B 级处理；只有 A 级来源的，表述保留「据 X」。AI 写的摘要也是二手。
- **媒体当闹钟，不当货源**。要认真推演的事，至少回到一份实际打开过的一手原件。打不开就写「未核到一手（原因）」，不编链接。
- **事件层不出现「我」**：不写我持有什么、盯着什么。和我有关的，写进单独的「对我层」。
- **下一步只用四个动词**：看 / 核 / 等 / 对照。不是买卖指令。真要动仓位，走 `yms-gate`。
- **不硬凑**：没有够分量的事，就写「今日无需推演」。
- **旧闻翻新**：写进事件层之前，先查这件事第一次公开是什么时候。几个月前的旧事被当成新闻推进来，标「旧闻翻新」，不进今天的变化。
- 时间写清时区（北京时间 / 美东时间）。
