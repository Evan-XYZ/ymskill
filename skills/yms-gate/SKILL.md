# 做 · yms-gate

> 研究和策略解决「该不该买」，门禁解决「现在这个价、这个仓位、这个心态，按不按下去」。
> 来自《AI 投资指南》05 操盘层 · 01 认知篇 §三

## 这个模块里有什么

| 你说 | 做什么 | 读 |
|:---|:---|:---|
| 「我想买」「想加仓」「过一下门禁」 | 四问逐条审：动机、审计、时机、这笔是哪类交易打算拿多久 | `references/buy-gate.md` |
| 「我想卖」「要不要走」「拿不住了」 | 把当初的买入理由和认错条件原文摆回来，问你触发的是同级别的证据还是一两天的波动 | `references/exit-check.md` |
| 「帮我做个操盘台」 | 按你的档案生成单文件本地操盘台：决策台 + 计划台，门禁写死在工具里 | `references/trading-desk.md` |

只读对应的那一份。

## 开工前（三个动作共用）

1. 先认文件夹：根目录有 `总入口暗号.md` 的是 YMOS，说明书换成根目录的 `YMSKILL_ADAPTER.md`（没有就用 `yms-setup` 建文件夹里内置的 YMOS 映射；策略档案按映射找不到时，照内置映射里的兜底再找一遍，适配页是旧版的也照做），下面各步的路径一律按映射换，按本节末尾「在 YMOS 文件夹里」办，不当成没初始化。其他文件夹读说明书（`AGENTS.md` / `CLAUDE.md`）和「路径映射」。
2. 读 `01_我的投资框架/Strategy_Profile.md` 和 `长期规则.md`：机会分类、每类的打算拿多久、什么时候认错、仓位上限、能否亏损加仓、红线。
3. 读 `04_决策与交易记录/`：这只标的有没有在持仓、当初的记录、门禁日志。

**没有投资文件夹时**：买入门禁照跑，结果先给在对话里；需要存文件的（比如整理好的交割单），放进当前目录的 `ymskill_试用/`。结束时问要不要建文件夹（`yms-setup`），把结果挪进去。其余动作先提示建文件夹。

**在 YMOS 文件夹里**（根目录有 `总入口暗号.md`）：买入门禁、卖出对照交给 YMOS 的「我想买」「加仓」「我想卖」，操盘台用 YMOS 的 Console，不另建门禁日志和操盘台。用户点名 `/yms-gate` 才用这里的版本，门禁日志追加到 `Brain/决策审计/门禁日志.md`（`Brain/买入卖出决策/` 和 `Brain/决策审计/` 里 Console 写的文件只读）。策略档案缺了或还是空模板，门禁照跑，结论只算候选，标「候选·无档案」，并提示先说「配置一下我的内核」（以根目录 `YMSKILL_ADAPTER.md` 为准；没有这个文件就按 `yms-setup` 建文件夹里的 YMOS 映射）。

## 这个模块的规矩

- **不下单**。这个模块、操盘台、整套 Skills 都不接任何券商接口。门禁通过只是「你的计划写清楚了」，不是「可以买」；真实买卖你自己在券商 App 上手动完成。
- **收盘后决策，开盘只执行**。交易时段里出现计划外的新标的，直接提示：「盘中不临时新增没计划过的标的。」
- **买入理由决定由谁来当退出的裁判**。用什么级别的理由买，就用什么级别的证据卖。
- **类型标签成交后不改**。波段买的，亏了不许改叫长投。
- **只追加**：门禁、卖出对照的结论只在 `04_决策与交易记录/门禁日志.md` 末尾追加。被拦截也要记一条。
- **不替你放宽**：档案里的仓位上限、止损规则，临时要求放宽，提示走 `yms-review` 的规则变更。
- 盈亏和资金量只用百分比，不写金额。
