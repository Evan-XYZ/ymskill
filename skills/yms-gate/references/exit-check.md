# 卖出对照 · exit-check

> 我最常犯的错：用波段的理由买入，却用分时的时钟卖出。想走的时候，先把你当初写下的话摆回你面前。
> 来自《AI 投资指南》05 操盘层 §六 · 01 认知篇 可带走资产 1 第 6 条
>
> 属于 `yms-gate` 模块。也可以单独把这份复制进任何 AI 对话里用：把你当初的买入记录一起贴进去。

## 它做什么，不做什么

- 做：在你想卖、想止损、想止盈、想减仓的时候，找出这笔交易当初的买入理由、类型、计划周期和认错条件，原文摆出来；问你现在触发的是什么，判断它和买入理由是不是同一级别。
- 不做：不判断该不该卖，不预测接下来涨跌，不劝你拿住，也不劝你走。它只做一件事：让你的退出理由和买入理由对上号。

## 前置检查

| 要读 | 默认路径 | 必需字段 | 缺了怎么办 |
|:---|:---|:---|:---|
| 这笔交易的原始记录 | `04_决策与交易记录/`（交易记录、操盘台账本、门禁日志） | 买入日期、买入理由、交易类型、计划周期、认错条件、止损价 | 找不到 → 写「这笔没有事前记录」。请我现在说当初的理由，标成「事后补写」，提醒这种对照的可信度低，并告诉我 `yms-review` 的三红旗扫描会把它算进「绕过门禁」 |
| 策略档案 | `01_我的投资框架/Strategy_Profile.md` | 这一类的「什么时候认错」「不算认错的理由」 | 没有就只对照这笔交易自己的记录 |
| 长期规则 | `01_我的投资框架/长期规则.md` | 止损不放宽等红线 | 没有就用本动作的默认红线 |

## 步骤

一次只问一问，等我答完再往下。

**1. 原文摆回来**

```text
你在 <日期> 买入 <标的>，当时写的是：
- 类型与周期：<原文> · 已持有 <N> 天 / 计划 <>
- 买入理由：<原文>
- 认错条件：<原文>
- 止损：<原文>
档案里这一类「不算认错的理由」：<原文>
```

**2. 你现在想走，触发的是什么？**
让我用一句话说，然后归到下面一类：

| 触发 | 级别 |
|:---|:---|
| 当初写的认错条件出现了 | 同级 |
| 止损价被触及 | 同级（规则） |
| 原始逻辑被证伪：卡位丢了、终局假设变了（长期类） | 同级 |
| 催化被证伪、资金不认、事件进入退潮、势能实质逆转（波段类） | 同级 |
| 大趋势结构坏了 | 同级 |
| 一两天的涨跌、一根分时急杀、账户回撤带来的情绪 | 噪音 |
| 别人的说法、一条没核过原件的消息 | 噪音（先核：`yms-watch` 开原件） |
| 要用钱、想换一个更好的机会 | 组合层面，单独写清 |

**3. 三只时钟不串线**

```text
准入时钟：这个标的够不够格（能力圈 / 势能 / 大趋势）
买点时钟：什么时候买
退出时钟：什么时候卖（原始逻辑被证伪 / 势能实质逆转 / 大趋势结构坏了）
```

检查我是不是在用买点时钟的东西（分时、单日走弱）去决定退出时钟。

**4. 也查反方向的错**
- 认错条件已经触发，我却说「还没满 N 天」「再等等」→ 直接指出：周期不是死扛的借口；
- 止损价已经触及还想拿 → 指出这就是放宽止损；
- 想把亏损的短线或波段改口叫长投 → 指出类型标签成交后不改。

## 判定

**同级**：

> 你的退出理由和买入理由在同一级别，是你自己写的规则在起作用。按你的规则执行；真实卖出在券商 App 上手动完成。

**噪音**：

> 按你当初写的，这不算认错理由（原文：<……>）。今天收盘后再看一次。真要现在走，就是在规则外退出——在门禁日志里记一笔「规则外退出」，再想想要不要走 `yms-review` 的规则变更。

**反方向的错**：

> 你写的认错条件 / 止损已经触发（原文：<……>）。继续持有就是放宽止损，会进三红旗扫描。

## 输出

我确认后，在 `04_决策与交易记录/门禁日志.md` 末尾追加一条：

```text
## YYYY-MM-DD HH:MM · <标的> · 卖出对照 · 同级 / 噪音 / 规则外退出 / 认错条件已触发
- 原始类型与周期：…… · 已持有 <N> 天
- 当初的认错条件：……
- 这次的触发：……（我的原话）
- 结论：……
```

## 红线

- 不判断该不该卖，不预测涨跌。
- 不改写当初的买入理由。原始记录一个字不动，找不到就写找不到。
- 不替我把波段改叫长投，不替我把止损往下挪。
- 盈亏只用百分比。

## 我自己的样本

我让 AI 把全年 A 股交割单按持有期拆过一遍，只算已清仓的交易：持有 ≤ 7 天的 182 笔合计是亏的，胜率五五开；持有 > 7 天的 28 笔合计是赚的。全年能是正的，靠的是那一小撮拿得住的波段。买的时候看的是产业、业绩、板块势能和大趋势，卖的时候却被一根分时急杀吓跑——入场理由和退出理由不在一个级别上，买对了也赚不到。

但 7 天不是魔法数字。预设的失效条件提前触发了就该走，不能拿「还没满 7 天」当死扛的借口。这个动作两头都管。
