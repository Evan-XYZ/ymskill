# ymskill 总入口 · yms

> 不知道该用哪个，从这里开始。你不用记 28 个动作的名字，说你现在的情况就行。
> 规矩以仓库根目录的 `AGENTS.md` 为准：不下单，不替你做买卖决定，你没写清的地方不替你编。

## 你可以这样用

| 你说 | 做什么 |
|:---|:---|
| `/yms 新手入门` | 讲清这套东西是什么、不是什么，第一次怎么走（见下面「新手入门」） |
| `/yms 从哪开始` | 起点诊断：问 5 个问题，判断你卡在哪一段（读 `references/start-here.md`） |
| `/yms <你现在的情况或问题>` | 推荐 1 个主动作，最多再加 2 个辅助，说明为什么，然后交给对应模块 |
| `/yms 更新` | 更新 ymskill，不动你的文件夹（见下面「更新」） |

## 怎么推荐

1. 先读用户投资文件夹的说明书（`AGENTS.md` / `CLAUDE.md`）。找不到 → 还没初始化，问一句：「想先试一下，还是先把文件夹建起来？」
   - 先试一下 → 从下面「不用准备就能试的」里，按他手里有什么挑一个；做完问他要不要建文件夹，把结果存下来；
   - 先建 → `yms-setup` 的建文件夹。
2. 按下面的全目录，找和用户这句话最贴的一个动作。规矩：
   - 要审一件事、一家公司，却没说它属于哪类机会 → 先 `yms-think` 两把尺子；
   - 说「想买 / 想加仓 / 想卖 / 拿不住」→ `yms-gate`；
   - 想把流程交给定时任务 → 先查那条流程有没有手动跑满三期，没满就推荐先手动跑；
   - 说不清卡在哪 → 起点诊断。
3. 输出：

```text
推荐：<模块> · <动作>（主）
为什么：<一句话，引用用户的原话>
辅助（可选，最多 2 个）：<模块> · <动作>，<什么时候用>
要准备的材料：<这个动作开工前要读的文件或要你给的东西>
```

4. 用户同意后：能调用 Skill 的工具，直接调用对应模块；不能的，告诉用户打开哪一份 `references/<动作>.md`，把正文复制进对话。

一次只推荐一个主动作，不要把七个模块都推给他。

## 不用准备就能试的

没有投资文件夹、没写策略档案，这几个动作也能跑出东西：

| 你手里有 | 先试 | 你会看到 |
|:---|:---|:---|
| 券商导出的交割单 | `yms-review` 持有期复盘 | 你的钱赚在哪个持有期、亏在哪个持有期 |
| 一条让你心动的新闻 | `yms-watch` 开原件核实 / 事件分级 | 原件说了什么、没说什么；这件事有多大分量 |
| 一笔正想下的单 | `yms-gate` 买入门禁 | 四问把你的计划问清楚（没有档案，第 4 问靠你临场回答） |
| 一家公司，不知道贵不贵 | `yms-think` 反向 DCF | 当前市值要求它未来每年长多少 |
| 一段想法 | `yms-brainstorm` 记下来 | 原话存档；只建一个 BrainStorm 就能用 |

试完说一句：「这些东西存在对话里，下次就没了。要不要现在建文件夹，把它存进去？」

## 新手入门

用三段话讲清楚，再问一句「你的投资文件夹放在哪」：

1. **它是什么**：一套公共的投资流程动作，加一个你自己的文件夹。动作管怎么看变化、怎么开原件、怎么用尺子量、怎么过门禁、怎么记账；文件夹里是你做哪几类机会、每一类用什么尺子、什么时候认错、你的交易和复盘。每个动作开工前先读你的文件夹，你没写的部分，它停下来告诉你缺什么。
2. **它不是什么**：不荐股，不预测，不给目标价，不接任何交易接口。真实买卖你自己在券商 App 上手动完成。
3. **第一次怎么走**：建文件夹 → 写策略档案 → 定观测清单 → 之后每天跑一次每日变化。自动化永远放在最后。

## 更新

- 用你当初装的方式再装一次就是更新：Skills CLI 再跑一次安装命令；Claude Code 插件在插件管理里更新；手动复制的，在仓库目录里 `git pull`，再把 `skills/` 下的文件夹复制过去。
- 更新只换 Skills，**不碰用户的投资文件夹**。
- 用户自己改过某个动作文件的，更新前先提醒他备份那一份。

## 红线

- 不给买卖建议，不预测涨跌。推荐的永远是一个研究或纪律动作，不是一个标的。
- 不替用户选投资风格。他说「说不清」，就照实写「说不清」。
