# 起点诊断 · start-here

> 不用 28 个动作都用。先找到你卡在哪一段，从那一段开始。
> 来自《AI 投资指南》00 全景导读 · 07 Agent 篇 §五
>
> 属于总入口 `yms`。也可以单独把这份复制进任何 AI 对话里用。

## 它做什么，不做什么

- 做：一次问一个问题，共 5 个；问完指出你当前最大的卡点在哪一段，推荐先用的 1–2 个动作和先读的 1–2 篇文章，再给一件本周就能做、不超过 30 分钟的小事。
- 不做：不给任何具体股票或买卖建议，不评价你的水平，也不推荐你换一种投资风格。

## 前置检查

| 要读 | 默认路径 | 用来做什么 | 缺了怎么办 |
|:---|:---|:---|:---|
| 说明书 | `AGENTS.md` / `CLAUDE.md` | 判断文件夹有没有初始化 | 没有不阻断，结论里把 `vault-init` 排在第一步 |
| 策略档案 | `01_我的投资框架/Strategy_Profile.md` | 已经写过的问题不再问 | 没有就五问全问 |

## 步骤

一次只问一个，等我答完再问下一个：

1. 你投资多久了，主要在哪个市场，大概属于哪种风格（长期持有 / 波段 / 短线 / 说不清）？
2. 你过去最大的几次亏损或错过，更像是「没看对」，还是「看对了没做对 / 没拿住」？
3. 你每天花多少时间看信息？看完能不能说清「今天什么变了」？
4. 你能不能用一页纸写清自己的买入理由、认错条件和打算持有多久？
5. 你现在用过哪些 AI 工具（Claude Code / Codex / 豆包电脑版 / WorkBuddy / 其他），愿意每周花多少时间搭自己的流程？

## 判断卡点

| 卡点 | 典型回答 | 先用 | 先读 |
|:---|:---|:---|:---|
| **信息** | 看很多，说不清今天什么变了 | `yms-setup` 建文件夹 → 观测清单 → `yms-watch` 每日变化 | 02 基建篇 · 03 投研层 |
| **策略** | 有判断但散在脑子里，写不出一页纸 | `yms-setup` 策略档案 → `yms-think` 两把尺子 | 04 策略层 |
| **执行** | 收盘想明白，盘中又冲动；看对了没拿住 | `yms-gate` 买入门禁 → 卖出对照 → 操盘台 | 05 操盘层 |
| **复盘** | 有成交记录，复盘容易自欺，一亏就想改规则 | `yms-review` 持有期复盘 → 三红旗 → 规则变更 | 06 进阶篇 · 01 认知篇 |
| **自动化** | 已经有几条流程每天在跑，触发它们成了负担 | `yms-autopilot` 定时任务说明 → 主控心跳 | 07 Agent 篇 |

两条判断规矩：

- 第 2 问答「看对了没做对 / 没拿住」，卡点优先判执行或复盘，不判信息。
- **自动化永远放在最后。**只有已经有流程手动跑满三期，才推荐 `yms-autopilot`；否则就算用户想要，也先把那条流程手动跑起来。
