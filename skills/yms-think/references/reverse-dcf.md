# 反向 DCF · reverse-dcf

> 不问它将来值多少钱，只倒推当前市值隐含了多高的增长要求，再看这个要求现不现实。
> 来自《AI 投资指南》04 策略层 §六.1
>
> 属于 `yms-think` 模块。能跑 Python 的环境用 `scripts/reverse_dcf.py` 算，结果确定；只能对话的工具，把下面的公式和数字一起贴进去让 AI 算，并要求它列出计算过程。

## 它做什么，不做什么

- 做：用当前市值（已知事实）倒推未来 3 年、5 年必须保持的年复合增速，再拿行业天花板和常识去校验这个要求，最后给出「显著安全边际 / 合理定价 / 已被透支」的定性和依据。
- 不做：不算「合理估值」，不给目标价。直接问 AI「值多少钱」，它会给你一个看起来很精确、其实没意义的数字——正向 DCF 对远期假设太敏感。

## 前置检查

| 要读 | 从哪来 | 必需字段 | 缺了怎么办 |
|:---|:---|:---|:---|
| 当前市值 | 行情数据（写明日期） | 市值、币种 | 问我，或标「待核」 |
| 基准自由现金流 | 最近一期年报 / TTM（S 级原件） | 自由现金流；没有就用净利润，并写明替代 | 拿不到原件 → 标「未核到一手」，结论最高按「待核」 |
| 净负债 / 净现金 | 资产负债表 | 有息负债 − 现金 | 用股权自由现金流时可以不填 |
| 折现率、永续增长率 | 我来定 | 常用 8%–10%、2%–3% | 我没给就用 9% / 2.5%，并在输出里写明是默认值 |
| 行业规模和渗透率 | 行业数据（标来源级别） | 第 2 步的现实性校验 | 没有就只能做到第 1 步，标【存疑】 |

基准自由现金流为负或接近 0 → 反向 DCF 不适用，直接说明，不硬算。

## 步骤

**1. 倒推隐含增速**

```bash
python3 "<本 Skill 目录>/scripts/reverse_dcf.py" --market-cap <市值> --fcf <基准FCF> --rate 0.09 --terminal 0.025 --years 3,5
# 用公司自由现金流（FCFF）时，加 --net-debt <净负债>，净现金写负数
```
`<本 Skill 目录>` 是 `yms-think` 这个模块所在的文件夹（加载 Skill 时会告诉你），不是用户的投资文件夹。

没有 Python 时的公式（两段式）：

```text
价值 = Σ(t=1..N) FCF0·(1+g)^t / (1+r)^t + [FCF0·(1+g)^N·(1+gT) / (r−gT)] / (1+r)^N
求 g，使 价值 = 市值 + 净负债
```

**2. 现实性校验**
要支撑当前市值，N 年后的自由现金流是现在的几倍？结合行业规模和渗透率上限：这个增速现实吗？是不是要求它 5 年后吃下行业绝大部分份额或利润池？

**3. 敏感性**
实际增速比隐含要求低 30% / 50% 时，价值较当前市值的回撤空间各是多少（脚本第 2 张表）。折现率和永续增长率各动一档，隐含增速变多少（第 3 张表）。

**4. 定性**
显著安全边际 / 合理定价 / 已被透支（完美预期定价），写清是哪几条依据让你这么判断。

## 输出

```markdown
- 隐含增速：3 年 <> / 5 年 <>；5 年后 FCF 需为现在的 <> 倍
- 现实性：……（行业规模 <> · 渗透率上限 <> · 来源）

- 定性：显著安全边际 / 合理定价 / 已被透支，依据：……
- 存疑：……

```

## 红线

- 不给目标价，不给买卖建议。
- 输入数字标报告期和来源；默认参数要写明是默认。
- 现金流为负时不硬算。

## 我自己的样本

普通问法和模具问法的差别：「帮我写一份白酒龙头的分析报告」，得到的是一份什么都讲、什么都没法检验的报告；「用反向 DCF，从当前市值倒推未来 5 年隐含的复合增速，再看这个要求在当前消费环境下现不现实」，得到的是一个可以拿行业数据去对的数字。
