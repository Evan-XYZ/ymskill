# 历史资料入职 · history-onboarding

> 你过去几年的投资日志、复盘和感悟，是策略的来路。旧资料先变成地图，再变成上下文；不能直接变成规则。
> 来自《AI 投资指南》04 策略层 §七（历史投资资料）
>
> 属于 `yms-brainstorm` 模块。需要能读写本地文件的 Agent；只能对话的工具，一次贴几份，按下面的口径逐份建索引。

## 它做什么，不做什么

- 做：把你放进来的旧日志、复盘、个股研究、旧规则做成一份索引（有什么、在哪、什么时期、什么主题），再抽代表性的样本写一份阶段梳理：不同时期你信什么、反复出现的行为模式、你现在的自我描述和当时的记录哪里对不上。
- 不做：不改原文、不移动原件，不做「一篇大总结」，不从旧日志直接生成策略档案，不替你填仓位、止损、持有期。

## 前置检查

| 要确认 | 怎么确认 | 情况不对怎么办 |
|:---|:---|:---|
| 处理哪些文件 | 只处理我放进 `06_BrainStorm/历史资料/原始资料/` 的，或我明确指定的 | 我没授权的，不递归扫我的整个笔记库、个人目录或聊天记录 |
| 有没有敏感信息 | 读的时候留意账户号、身份证明、密码、Key | 不在对话和索引里回显，索引里标「私密」 |
| 文件能不能读 | 列清单 | 读不了的（扫描件、图片、加密文件）列进「待处理」，问我怎么转 |

默认不联网、不上传。需要转格式的，在同目录生成 Markdown 副本，原件不动。

## 步骤

**1. 盘点，不先总结**
建一份文件清单，按 `templates/资料索引.md` 写进 `06_BrainStorm/历史资料/资料索引.md`。每份记：路径、内容时期、市场和主题、材料类型（日志 / 复盘 / 感悟 / 规则 / 研究）、观点状态（当时认可 / 已修订 / 已放弃 / 未知）、读取状态、隐私级别。
认不出日期就写「未知」，不拿文件修改时间冒充内容发生的时间。

**2. 按阶段和主题建地图**
时间阶段或市场环境；市场与策略结构；主题（入场、认错、仓位、期限、选股、退出、情绪、执行）。文件多的时候，不一开始把全文塞进同一个上下文。

**3. 代表性抽样**
覆盖差异，不只挑印象最深或赚得最多的：不同市场阶段；成功和失败；判断对了执行错了、判断错了碰巧赚了；后来改口或反复摇摆的主题；和我现在的自我描述一致的、不一致的。每条提炼都保留来源文件和原文位置；分不清是当时观点还是事后总结的，标出来。

**4. 写阶段梳理**
按 `templates/历史资料梳理.md` 写到 `06_BrainStorm/历史资料/梳理/YYYY-MM-DD_阶段梳理.md`，至少包括：材料覆盖和缺口；不同时期的策略和裁判；反复出现的模式（附反例）；自我描述和记录的矛盾；当前仍认可 / 已放弃 / 不确定的原则；需要我回答的问题。

**5. 发现矛盾就问我**
「这条旧规则你现在还认可吗？」不拿旧日志覆盖我今天明确的选择，也不把我今天的自我描述当成历史事实。

## 之后怎么用

- 日常头脑风暴：默认不读历史资料；话题碰到索引里的某个主题时，才打开一两份代表原文。
- 写策略档案（`yms-setup`）：先读索引和最近一次梳理，用来问我问题，不用来替我回答。
- 复盘（`yms-review`）：旧资料能帮你看清规则的来路和矛盾；要证明某条规则更有效，仍然要靠真实的交易记录和平仓复盘。

## 输出

- `06_BrainStorm/历史资料/资料索引.md`
- `06_BrainStorm/历史资料/梳理/YYYY-MM-DD_阶段梳理.md`
- 对话里：这次读了什么、没读什么、下次怎么继续追加。

## 红线

- 原件不改、不移动、不删除。
- 不从旧日志直接写长期记忆、策略档案或长期规则；只列候选，等我确认。
- 不回显账户号、身份证明、密码、Key。
- 不给买卖建议。
